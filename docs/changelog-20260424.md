# SteelLink Frontend 迭代日志 — 2026.04.24

## 本次迭代：买家端登录体验优化

PR: https://github.com/Taishi-co/SteelLink-frontend/pull/8

---

### 一、登录页 UI 统一

买家端登录页从简单的居中卡片改为与卖家端一致的左右布局风格。

左侧展示平台品牌信息和三个核心卖点卡片（海量商品 / 透明报价 / 订单追踪），右侧是登录/注册表单。

[插图：买家端新登录页 — 左右布局全貌]

---

### 二、跳过登录，先逛逛

登录卡片底部新增「暂不登录，先逛逛 →」按钮，点击直接进入首页浏览商品。

未登录状态下可以正常浏览首页、商品列表、商品详情，只有在下单等需要身份的操作时才要求登录。

[插图：登录页底部「先逛逛」按钮]

---

### 三、Header 登录状态感知

之前 Header 始终显示「登录/注册」按钮，即使已经登录了也不变。

现在根据登录状态动态切换：
- 未登录：显示「登录」和「注册」按钮
- 已登录：显示用户头像和用户名，点击下拉菜单有「我的订单」和「退出登录」

首页 HomeHeader 和内页 Header 都做了同样的处理。

[插图：未登录状态 Header]

[插图：已登录状态 Header — 头像下拉菜单]

---

### 四、登录后自动回跳

之前未登录点下单会跳到登录页，但登录成功后只会回到首页，丢失了用户正在看的商品。

现在通过 URL 参数 `?redirect=` 记录来源页面：
- 商品详情页点下单 → 跳到 `/login?redirect=/products/123`
- 登录成功 → 自动跳回 `/products/123`
- API 401 拦截器同样带 redirect 参数

[插图：商品详情页点下单提示登录 → 登录后回到原页面]

---

### 五、API 地址本地配置

买家端和卖家端新增 `.env.local` 文件配置 `VITE_API_URL`，指向本地主后端 8081 端口。该文件被 gitignore，拉新代码不会被覆盖，解决了之前每次 pull 都要手动改端口的问题。
