# AI采购历史操作按钮 Feature Spec

## 基本信息

- Feature ID: SL-FE-AI-PROCUREMENT-HISTORY-ACTIONS
- Feature 名称: AI采购历史操作按钮
- 负责人: Codex
- 目标上线环境: buyer-app production

## 背景

买家在 AI采购首页的“我的AI采购”中查看历史记录时，需要对历史采购对话进行复用和查看。当前历史记录整卡点击进入详情，缺少明确动作，用户无法直接复制原始采购对话或快速发起同样需求。

## 范围

### In Scope

- 在买家端 AI采购首页“我的AI采购”列表中，为每条历史记录提供三个按钮：再买一次、查看详情、复制。
- “再买一次”将该历史记录的原始采购对话填回输入框，并清空当前步骤上下文，作为新采购重新解析。
- “查看详情”沿用当前历史详情打开逻辑，进入已保存采购详情。
- “复制”复制历史记录的原始采购对话文本，并提供成功或失败提示。

### Out of Scope

- 不新增后端 API。
- 不改变 AI采购历史保存逻辑。
- 不改变订单、融资、物流匹配流程。

## 交互与页面影响

- 受影响页面: `apps/buyer-app/src/pages/AiProcurement/index.tsx`
- 新增页面: 无
- 路由变化: 无
- 菜单变化: 无

## 数据与接口影响

- 受影响 API: 无新增；继续使用 `/ai-procurements/mine` 返回的 `prompt`、状态和详情字段。
- 请求/响应变化: 无
- 环境变量变化: 无

## 权限影响

- 受影响角色: 已登录买家
- 新增/调整权限: 无

## 验收标准

1. 已登录买家在“我的AI采购”每条记录上可以看到“再买一次”、“查看详情”、“复制”三个按钮。
2. 点击“再买一次”后，采购对话框填入该历史记录的原始采购对话，当前历史详情上下文被清空，可重新解析。
3. 点击“查看详情”后，进入该历史记录的详情步骤。
4. 点击“复制”后，将该历史记录的采购对话复制到剪贴板，并显示操作反馈。
