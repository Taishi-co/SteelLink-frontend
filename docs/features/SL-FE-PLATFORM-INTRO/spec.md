# Feature Spec

## 基本信息

- Feature ID: SL-FE-PLATFORM-INTRO
- Feature 名称: 平台介绍页
- 负责人: Codex
- 目标上线环境: buyer-app

## 背景

买家端顶部导航已有“平台介绍”入口，但当前仍是占位页。需要补齐正式内容，让未登录访客和采购企业可以了解 SteelLink 的定位、最新平台动态和联系方式。

## 范围

### In Scope

- 替换 `/about` 占位页。
- 页面包含三个核心板块：平台简介、最新新闻、联系我们。
- 保留现有首页布局与顶部导航。
- 将页脚“联系我们”指向 `/about#contact`。

### Out of Scope

- 不新增后端新闻接口。
- 不新增内容管理后台。
- 不修改登录、商城、AI采购等交易功能。

## 交互与页面影响

- 受影响页面: 买家端 `/about`。
- 新增页面: `apps/buyer-app/src/pages/About/index.tsx`。
- 路由变化: `/about` 从占位页替换为正式页面。
- 菜单变化: 顶部导航文本不变，页脚联系我们链接调整为同页锚点。

## 数据与接口影响

- 受影响 API: 无。
- 请求/响应变化: 无。
- 环境变量变化: 无。

## 权限影响

- 受影响角色: 游客、买家用户。
- 新增/调整权限: 无，页面公开可访问。

## 验收标准

1. 访问 `/about` 可以看到平台简介、最新新闻、联系我们三个板块。
2. 顶部“平台介绍”导航仍能正确高亮。
3. 页脚“联系我们”可以定位到联系信息板块。
4. buyer-app lint/build 和 feature harness 通过。
