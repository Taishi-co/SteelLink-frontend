# Test Cases

| 用例 | 前置条件 | 操作 | 预期 |
| --- | --- | --- | --- |
| TC-01 商品缩略图 | 购物车接口返回 `image_url` | 打开 `/cart` | 商品信息列展示对应缩略图 |
| TC-02 可发货仓库 | 购物车接口返回 `warehouse_info` | 打开 `/cart` | 可发货仓库列展示仓库名称、编码和地址 |
| TC-03 缺省仓库 | 某商品未绑定仓库 | 打开 `/cart` | 页面显示“暂无绑定仓库”，数量修改和删除仍可用 |
| TC-04 缺省图片 | 某商品未返回图片 | 打开 `/cart` | 页面展示图片占位，不出现破版 |
