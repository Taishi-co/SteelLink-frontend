# COS Object Storage Uploads Frontend Test Cases

## 测试范围

- Feature ID: SL-STORAGE-COS-UPLOAD
- 测试负责人: Codex

## Happy Path

| 编号 | 场景 | 前置条件 | 步骤 | 期望结果 |
| --- | --- | --- | --- | --- |
| TC-01 | 卖家发布商品上传主图 | 已登录卖家，后端 COS 已配置 | 选择商品主图和审核资料，提交审核 | 前端先调用上传接口，再提交商品，商品保存真实 URL |
| TC-02 | 买家上传支付凭证 | 买家订单处于待支付 | 在订单详情选择凭证文件并确认 | 上传成功，订单支付凭证 URL 保存 |
| TC-03 | 买家上传签收凭证 | 买家订单处于配送中 | 在订单详情选择签收文件并确认收货 | 上传成功，订单完成并保存签收凭证 URL |
| TC-04 | 商城首页商品图展示 | 商品有 `images[0]` | 打开商城首页 | 热门商品卡片显示真实商品图 |
| TC-05 | 物流商企业认证上传资质 | 已登录且完成实名认证，后端 COS 已配置 | 选择物流商，上传营业执照、运输许可证、承运资质 | 三类文件均上传成功，提交企业认证时携带返回 URL |

## Exception Path

| 编号 | 场景 | 前置条件 | 步骤 | 期望结果 |
| --- | --- | --- | --- | --- |
| TC-EX-01 | 未选择凭证文件 | 打开上传支付凭证弹窗 | 直接确认 | 表单提示必须上传文件 |
| TC-EX-02 | 上传接口失败 | 后端 COS 未配置或网络失败 | 选择文件并确认 | 显示后端错误信息，业务接口不提交占位 URL |
| TC-EX-03 | 商品缺少主图 | 打开商品发布弹窗 | 不选择商品主图提交 | 表单阻止提交 |
| TC-EX-04 | 物流商资质上传接口失败 | 后端未支持 `enterprise_service_document` 或 COS 配置异常 | 上传运输许可证/承运资质 | 显示上传失败，企业认证不提交缺失资料 |

## 权限测试

| 编号 | 角色 | 场景 | 期望结果 |
| --- | --- | --- | --- |
| TC-AUTH-01 | 游客 | 直接调用上传接口 | 后端返回未授权，前端不会静默成功 |
| TC-AUTH-02 | 买家 | 上传订单凭证 | 由订单接口继续校验订单归属 |
| TC-AUTH-03 | 卖家 | 发布商品资料 | 由商品接口继续校验企业用户身份 |

## 回归关注点

- 买家订单时间线仍正常展示。
- 支付凭证和签收凭证链接仍使用现有详情展示逻辑。
- 卖家端商品发布的已有必填字段不受上传改造影响。
