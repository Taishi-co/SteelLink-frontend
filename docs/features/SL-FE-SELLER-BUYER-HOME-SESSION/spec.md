# Feature Spec

## 基本信息

- Feature ID: SL-FE-SELLER-BUYER-HOME-SESSION
- Feature 名称: 卖家中心返回买家首页保留登录态
- 负责人: Codex
- 目标上线环境: Web 前端

## 背景

用户在卖家中心点击“买家首页”时，买家端用户状态被清空。买家端与卖家端共用登录 token 和买家用户缓存，卖家端接口未授权清理不应等同于用户主动退出。

## 范围

### In Scope

- 调整卖家端未授权清理逻辑，支持保留买家共享会话。
- 保持卖家端显式退出登录、切换账号的全量退出行为不变。

### Out of Scope

- 不调整后端鉴权逻辑。
- 不新增登录、注册、角色权限页面。

## 交互与页面影响

- 受影响页面: 卖家中心顶部“买家首页”入口。
- 新增页面: 无。
- 路由变化: 无。
- 菜单变化: 无。

## 数据与接口影响

- 受影响 API: 卖家端 axios 401 响应处理。
- 请求/响应变化: 无。
- 环境变量变化: 无。

## 权限影响

- 受影响角色: seller / enterprise 用户。
- 新增/调整权限: 无。

## 验收标准

1. 卖家中心点击“买家首页”后，买家端仍能读取原有 token 和 `buyer_user`。
2. 卖家端接口返回 401 时，只清理卖家侧用户缓存，不清空买家共享会话。
3. 卖家端显式退出登录或切换账号仍会清空完整登录态。
