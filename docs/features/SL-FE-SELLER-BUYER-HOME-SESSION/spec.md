# Feature Spec

## 基本信息

- Feature ID: SL-FE-SELLER-BUYER-HOME-SESSION
- Feature 名称: 卖家中心返回买家首页保留登录态
- 负责人: Codex
- 目标上线环境: Web 前端

## 背景

用户在卖家中心点击“买家首页”时，买家端用户状态被清空。当前前端已使用统一的 `token/user` 存储和跨端 `switch-session` 接口，卖家端不能直接跳回买家首页并让买家端用卖家态初始化。

## 范围

### In Scope

- 卖家端“买家首页”入口先创建买家切换令牌，再跳转买家端登录页消费令牌。
- 保留失败兜底跳转，避免入口完全不可用。

### Out of Scope

- 不调整后端切换会话接口。
- 不调整买家端和卖家端显式退出登录行为。

## 交互与页面影响

- 受影响页面: 卖家中心顶部“买家首页”入口。
- 新增页面: 无。
- 路由变化: 无。
- 菜单变化: 无。

## 数据与接口影响

- 受影响 API: `POST /api/v1/auth/switch-session`。
- 请求/响应变化: 无。
- 环境变量变化: 无。

## 权限影响

- 受影响角色: seller / enterprise 用户。
- 新增/调整权限: 无。

## 验收标准

1. 卖家中心点击“买家首页”后，会通过 `switch_token` 切换到买家会话。
2. 买家端消费切换令牌后仍展示登录用户，不因卖家态初始化而清空状态。
3. 切换接口失败时仍可回到买家首页，但不改变现有退出登录行为。
