# Test Cases

## 测试范围

- Feature ID: SL-FE-BIDDING-PROCUREMENT-API-INTEGRATION
- 测试负责人: Codex

## Happy Path

| 编号 | 场景 | 前置条件 | 步骤 | 期望结果 |
| --- | --- | --- | --- | --- |
| TC-01 | 打开竞价大厅 | 后端服务启动 | 访问 `/bidding` | 统计、热门竞价、竞价成功来自接口 |
| TC-02 | 打开买家竞价模块 | 前端服务启动 | 点击买家竞价入口 | 跳转 `/bidding/buyer` |
| TC-03 | 打开卖家竞价模块 | 前端服务启动 | 点击卖家竞价入口 | 跳转 `/bidding/seller` |
| TC-04 | 打开集采大厅 | 后端服务启动 | 访问 `/procurement` | 统计和活动列表来自接口 |
| TC-05 | 打开集采详情 | 后端存在活动 | 点击活动“进入详情” | 跳转 `/procurement/:id` 并展示详情和日志 |

## Exception Path

| 编号 | 场景 | 前置条件 | 步骤 | 期望结果 |
| --- | --- | --- | --- | --- |
| TC-EX-01 | 后端不可用 | 停止后端 | 打开 `/bidding` 或 `/procurement` | 展示加载失败提示，不展示伪造业务数据 |
| TC-EX-02 | 集采活动不存在 | 后端返回 404 | 访问不存在的 `/procurement/:id` | 展示“集采活动不存在” |
