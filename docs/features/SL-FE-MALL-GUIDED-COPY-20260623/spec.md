# Feature Spec

## 基本信息

- Feature ID: SL-FE-MALL-GUIDED-COPY-20260623
- Feature 名称: 买家端主商城导购文案与展示优化
- 负责人: Codex
- 目标上线环境: buyer-app

## 背景

买家端首页与现货商城已经具备基础入口，但公开页文案仍偏演示化，对“这是一个面向产业集群的大宗商品交易平台”表达不够完整，也缺少围绕采购决策、履约协同、供应链金融的引导说明。上线前需要把主商城公开展示调整为更正式、更可信、更便于用户理解下一步操作的版本。

## 范围

### In Scope

- 优化买家端首页公开文案，突出大宗商品交易、集采协同、供应链金融和履约闭环。
- 优化现货商城页的导购表达，增加更明确的采购路径说明。
- 优化页脚和登录页的公开说明文字，统一平台对外口径。
- 保持现有公开路由与交易接口不变。

### Out of Scope

- 不新增后端接口。
- 不修改商品、订单、AI采购、集采等业务流程逻辑。
- 不调整权限模型和导航结构。

## 交互与页面影响

- 受影响页面: 买家端 `/`、`/mall`、`/login` 的公开展示，以及公共页脚。
- 新增页面: 无。
- 路由变化: 无。
- 菜单变化: 无。

## 数据与接口影响

- 受影响 API: 无新增 API，继续复用首页统计、商品分类、商品列表接口。
- 请求/响应变化: 无。
- 环境变量变化: 无。

## 权限影响

- 受影响角色: 游客、买家用户、拟入驻企业用户。
- 新增/调整权限: 无，均为公开访问内容优化。

## 验收标准

1. 首页首屏、能力说明、服务入口和底部 CTA 使用更正式的产业平台表述，明确“交易 + 履约 + 融资”定位。
2. 商城页能够向首次访问用户说明采购入口、选货逻辑和后续履约路径，文本以用户操作引导为核心。
3. 登录页和页脚的公开说明文案与首页口径一致，不再使用偏泛化的营销表述。
4. `./harness/verify.sh`、buyer-app lint、buyer-app build 通过。
