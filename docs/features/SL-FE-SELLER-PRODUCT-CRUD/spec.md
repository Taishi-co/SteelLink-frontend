# Feature Spec

## 基本信息

- Feature ID: SL-FE-SELLER-PRODUCT-CRUD
- Feature 名称: 卖家商品管理 CRUD
- 负责人: Codex
- 目标上线环境: seller-app 生产环境

## 背景

卖家后台商品管理已支持发布商品和补充审核资料，但列表缺少商品缩略图和完整详情视图，卖家也不能直接编辑核心商品字段或删除误建商品。需要将商品管理补齐为可日常维护的 CRUD 工作台。

## 范围

### In Scope

- 卖家商品列表展示首张商品图作为缩略图。
- 商品详情抽屉展示基础信息、交易字段、仓库信息、展示图片、审核资料和审核状态。
- 卖家可创建商品、编辑自有商品、删除自有商品。
- 编辑商品后重新进入平台审核。

### Out of Scope

- 不调整运营端审核流程。
- 不改买家端商品详情展示。
- 不新增批量导入或批量上下架。

## 交互与页面影响

- 受影响页面: `apps/seller-app/src/pages/Products/index.tsx`
- 新增页面: 无
- 路由变化: 无
- 菜单变化: 无

## 数据与接口影响

- 受影响 API:
  - `POST /api/v1/products`
  - `PUT /api/v1/products/:id`
  - `DELETE /api/v1/products/:id`
  - `GET /api/v1/products`
- 请求/响应变化: 新增卖家自有商品编辑和删除接口；编辑复用商品创建字段并将状态重置为待审核。
- 环境变量变化: 无

## 权限影响

- 受影响角色: seller/sales capability 用户。
- 新增/调整权限: 卖家只能编辑或删除所属企业商品。

## 验收标准

1. `/seller/products` 列表能看到商品缩略图、商品详情和资料数量。
2. 卖家可通过同一个弹窗创建和编辑商品，提交后列表刷新。
3. 卖家删除商品前有确认提示，删除后商品从列表移除。
4. 非商品所属企业不能编辑或删除商品。
