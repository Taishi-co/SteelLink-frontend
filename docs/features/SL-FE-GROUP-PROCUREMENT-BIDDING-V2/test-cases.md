# Test Cases

## 测试范围

- Feature ID: `SL-FE-GROUP-PROCUREMENT-BIDDING-V2`
- 测试负责人: Codex

## Happy Path

| 编号 | 场景 | 前置条件 | 步骤 | 期望结果 |
| --- | --- | --- | --- | --- |
| TC-01 | 买家查看项目大厅 | 后端已有竞价项目 | 访问 `/procurement` | 展示项目列表、状态与需求归集摘要 |
| TC-02 | 买家查看项目详情 | 已打开项目列表 | 点击项目卡片 | 进入 `/procurement/:id`，展示进度、中标摘要、申请信息 |
| TC-03 | 商品详情提交集采申请 | 买家已登录且商品详情可访问 | 打开商品详情并提交申请 | 申请成功并可在项目归集后看到项目状态 |
| TC-04 | 卖家查看可参与项目 | 卖家已登录 | 打开卖家端集采页 | 展示可参与项目和我的报价 |
| TC-05 | 卖家提交报价 | 卖家拥有已审核项目资格 | 填写价格、供货量、交期后提交 | 报价成功，列表展示最新报价 |
| TC-06 | 定标后查看结果 | 管理端已完成定标 | 刷新买家端和卖家端详情 | 展示中标状态、中标价或未中标状态 |

## Exception Path

| 编号 | 场景 | 前置条件 | 步骤 | 期望结果 |
| --- | --- | --- | --- | --- |
| TC-EX-01 | 游客访问买家项目详情 | 未登录 | 访问 `/procurement/:id` | 可看公开摘要，不可执行企业动作 |
| TC-EX-02 | 卖家未获资格报价 | 卖家未报名或未审核通过 | 提交报价 | 展示后端错误提示 |
| TC-EX-03 | 项目不存在 | 后端返回 404 | 访问不存在项目详情 | 页面显示空态 |
