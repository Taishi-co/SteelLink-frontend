# Feature Spec: 供求信息工作台

## 基本信息

- Feature ID: SL-FE-MATCHING-TAG
- Feature 名称: 买家端供求信息工作台
- 负责人: AI agent
- 目标上线环境: Web 买家端

## 背景

买家端主站需要在交易服务入口中提供“供求信息”标签，并提供独立供求信息页面，用于承接后续供需、仓储、物流撮合能力。该页面首屏需要展示平台撮合数据，再展示基于用户已有求购/供应信息的 AI 智能推荐，并提供发布供应、发布求购、仓储服务、物流服务及对应信息板块。

## 范围

### In Scope

- 在买家端顶部导航中新增“供求信息”入口。
- 新增 `/matching` 路由与供求信息页面。
- 在首页平台服务区新增“供求信息”服务卡片，并放在“现货商城”和“竞价交易”之间。
- 在 footer 平台服务列表中新增“供求信息”入口，并保持同样顺序。
- `/matching` 页面顶部展示“已发布信息数、撮合成功数、撮合金额数、今日新增数”。
- `/matching` 页面展示 AI 智能撮合推荐板块，包含推荐类型、匹配度、区域、价格、推荐理由和标签。
- `/matching` 页面展示“我的发布”板块，用户可看到自己发布的信息和撮合进展。
- `/matching` 页面展示“发布供应、发布求购、仓储服务、物流服务”四个入口。
- `/matching` 页面展示供应信息、求购信息、仓储服务信息、物流服务信息四个信息板块。

### Out of Scope

- 不实现真实撮合算法、提交表单、接口或后台配置。
- 不调整卖家端、管理端或后端接口。
- 不改动权限矩阵和登录鉴权逻辑。

## 交互与页面影响

- 受影响页面: 买家端首页、买家端公共 header、买家端公共 footer、供求信息页。
- 新增页面: `/matching` 供求信息页。
- 路由变化: 新增 `matching` 子路由。
- 菜单变化: 顶部导航新增“供求信息”，位置在“现货商城”和“竞价交易”之间。

## 数据与接口影响

- 受影响 API: 无。
- 请求/响应变化: 无。
- 环境变量变化: 无。

## 权限影响

- 受影响角色: 游客、已登录买家均可看到入口。
- 新增/调整权限: 无。

## 验收标准

1. 顶部导航展示顺序为：首页、现货商城、供求信息、竞价交易、集采大厅、平台介绍。
2. 点击“供求信息”进入 `/matching`，页面展示数据看板，包含“已发布信息数、撮合成功数、撮合金额数、今日新增数”。
3. `/matching` 页面展示 AI 智能撮合推荐板块，并体现根据已有供需信息生成推荐的业务语义。
4. `/matching` 页面展示“我的发布”板块，可看到自己发布的信息和意向数量。
5. `/matching` 页面展示四个业务入口和对应四类信息板块。
6. 本次变更不引入接口调用、权限判断或卖家端行为变化。
