## 回归关注点

- 现货商城 `/mall`、竞价交易 `/bidding`、集采大厅 `/procurement` 原入口仍可正常点击。
- 顶部导航选中态在 `/matching` 下正确高亮“信息撮合”。
- 首页服务区从 4 个卡片扩展为 5 个卡片后，桌面端布局不应遮挡文字。
- `/matching` 页面当前使用前端静态展示数据，后续接入接口时需要保持页面结构和空状态兼容。
