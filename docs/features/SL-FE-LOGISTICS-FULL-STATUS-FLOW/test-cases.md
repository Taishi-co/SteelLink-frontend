# 测试用例 - 前端

## TC-FE-01 卖家端物流竞价Tab
- 前置：订单处于物流竞价中(15)
- 步骤：切换到物流竞价Tab
- 预期：显示竞价状态和报价列表，每个报价显示物流公司、金额、司机/车辆信息

## TC-FE-02 卖家选择报价
- 前置：竞价中有多个报价
- 步骤：Radio选择一个报价 → 点击确认
- 预期：弹出确认弹窗，确认后订单状态更新

## TC-FE-03 卖家关闭竞价
- 前置：订单处于物流竞价中(15)
- 步骤：点击关闭竞价按钮
- 预期：竞价关闭

## TC-FE-04 卖家端物流进度展示
- 前置：订单有 shipment_task
- 步骤：查看订单详情
- 预期：显示4步进度条，当前步骤高亮，已完成步骤显示时间

## TC-FE-05 卖家对账确认
- 前置：订单状态为已收货(18)
- 步骤：点击对账确认按钮
- 预期：订单状态变为已对账(19)

## TC-FE-06 买家端物流进度展示
- 前置：订单有 shipment_task
- 步骤：查看订单详情
- 预期：物流仓储履约卡片显示4步进度条

## TC-FE-07 买家确认收货
- 前置：订单为运输中(17)或已送达(7)
- 步骤：点击确认收货按钮
- 预期：弹出确认弹窗，确认后订单变为已收货(18)

## TC-FE-08 物流端确认提货
- 前置：shipment_task=pending_pickup
- 步骤：点击确认提货 → 上传凭证图片 → 提交
- 预期：shipment_task更新为picked_up

## TC-FE-09 物流端确认送达
- 前置：shipment_task=picked_up
- 步骤：点击确认送达 → 上传凭证图片 → 提交
- 预期：shipment_task更新为delivered

## TC-FE-10 物流端上传签收
- 前置：shipment_task=delivered
- 步骤：点击上传签收 → 上传签收回单 → 提交
- 预期：shipment_task更新为signed
