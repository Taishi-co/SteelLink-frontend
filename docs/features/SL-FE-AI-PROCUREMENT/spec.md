# Feature Spec: AI采购流程

## 基本信息

- Feature ID: SL-FE-AI-PROCUREMENT
- Feature 名称: 买家端 AI采购流程
- 负责人: AI agent
- 目标上线环境: Web 买家端

## 背景

买家端需要将原“信息撮合”入口调整为“供求信息”，并新增“AI采购”入口。AI采购面向有明确采购目标的买家，允许用户用自然语言表达采购诉求，例如“帮我采购100套工业轴承，用于设备维修，需要申请订单融资”，页面需要可视化展示从对话指令到采购结果的自动化阶段。

## 范围

### In Scope

- 顶部导航去掉旧“供求信息”tag，将原“信息撮合”入口改名为“供求信息”。
- 新增“AI采购”导航入口和 `/ai-procurement` 路由。
- 新增 AI采购页面，展示采购对话输入示例。
- 可视化展示“指令解析、商品匹配、订单生成、融资匹配、审核提交”五个阶段。
- 首页服务区和 footer 平台服务入口同步调整。
- 当前页面使用静态前端演示数据，表达产品流程与状态。

### Out of Scope

- 不调用真实大模型、商品搜索、订单创建、融资申请或审核接口。
- 不实现聊天会话持久化、表单提交或审批工作流。
- 不调整后端、卖家端或管理端。

## 交互与页面影响

- 受影响页面: 买家端首页、公共 header、公共 footer、供求信息页、AI采购页。
- 新增页面: `/ai-procurement`。
- 路由变化: 新增 `ai-procurement` 子路由；保留历史 `/supply` 占位路由但不再作为导航 tag 展示。
- 菜单变化: 顶部导航展示“供求信息”和“AI采购”，不再展示旧 `/supply` 的“供求信息”tag。

## 数据与接口影响

- 受影响 API: 无。
- 请求/响应变化: 无。
- 环境变量变化: 无。

## 权限影响

- 受影响角色: 游客、已登录买家均可查看演示页面。
- 新增/调整权限: 无。

## 验收标准

1. 顶部导航不再出现两个供求相关入口；原“信息撮合”展示为“供求信息”。
2. 顶部导航新增“AI采购”，点击进入 `/ai-procurement`。
3. AI采购页展示示例指令“帮我采购100套工业轴承，用于设备维修，需要申请订单融资”。
4. AI采购页可视化展示“指令解析、商品匹配、订单生成、融资匹配、审核提交”五个阶段。
5. 首页服务区和 footer 入口与顶部导航命名一致。
