# Feature Spec

## 基本信息

- Feature ID: SL-FE-BIDDING-HALL
- Feature 名称: 竞价交易前端大厅增强
- 负责人: Codex
- 目标上线环境: buyer-app

## 背景

买家端已有“竞价交易”导航，但当前仍是占位页。需要将其完善为竞价大厅，让企业先看到平台竞价规模、热门活动、成交案例，并能按买家或卖家角色进入对应竞价模块。

## 范围

### In Scope

- 替换 `/bidding` 占位页为竞价大厅。
- 展示进行中竞价、竞价成功、总成交金额、参与企业四项统计。
- 展示买家竞价与卖家竞价两个模块入口，点击进入对应模块页。
- 展示热门竞价列表，包含竞价编号、标的、品类、数量、当前价、降幅、参与企业、剩余时间和进度。
- 展示竞价成功列表，包含采购方、中标方、成交金额、节省比例和成交时间。
- 新增 `/bidding/:module` 承接买家/卖家竞价工作台框架。

### Out of Scope

- 不新增后端 API。
- 不提交真实竞价单。
- 不实现真实报价、保证金、合同签署与权限校验。

## 交互与页面影响

- 受影响页面: `/bidding`
- 新增页面: `apps/buyer-app/src/pages/Bidding/index.tsx`、`apps/buyer-app/src/pages/BiddingModule/index.tsx`
- 路由变化: `/bidding` 从占位页替换为竞价大厅；新增 `/bidding/buyer` 与 `/bidding/seller`。
- 菜单变化: 无。

## 数据与接口影响

- 受影响 API: 无。
- 请求/响应变化: 无。
- 环境变量变化: 无。

## 权限影响

- 当前大厅公开可访问。
- 后续接真实业务时，买家竞价模块应校验采购方企业身份，卖家竞价模块应校验供应方企业身份。

## 验收标准

1. `/bidding` 展示竞价大厅。
2. 页面顶部展示四项竞价统计。
3. 页面包含买家竞价与卖家竞价入口。
4. 点击入口可进入 `/bidding/buyer` 或 `/bidding/seller`。
5. 页面展示热门竞价和竞价成功两个信息板块。
