# Test Cases

## 测试范围

- Feature ID: SL-FE-BIDDING-HALL
- 测试负责人: Codex

## Happy Path

| 编号 | 场景 | 前置条件 | 步骤 | 期望结果 |
| --- | --- | --- | --- | --- |
| TC-01 | 打开竞价大厅 | 买家端可访问 | 访问 `/bidding` | 页面展示“竞价交易”和大厅内容，不再展示占位页 |
| TC-02 | 查看统计 | 打开 `/bidding` | 查看顶部统计区 | 展示进行中竞价、竞价成功、总成交金额、参与企业 |
| TC-03 | 进入买家竞价模块 | 打开 `/bidding` | 点击“买家竞价”的“进入模块” | 跳转到 `/bidding/buyer` 并展示买家竞价工作台 |
| TC-04 | 进入卖家竞价模块 | 打开 `/bidding` | 点击“卖家竞价”的“进入模块” | 跳转到 `/bidding/seller` 并展示卖家竞价工作台 |
| TC-05 | 查看热门竞价 | 打开 `/bidding` | 查看“热门竞价”板块 | 展示竞价编号、标的、当前价、参与企业和剩余时间 |
| TC-06 | 查看竞价成功 | 打开 `/bidding` | 查看“竞价成功”板块 | 展示采购方、中标方、成交金额、节省比例和成交时间 |

## Exception Path

## 权限测试

| 编号 | 角色 | 场景 | 期望结果 |
| --- | --- | --- | --- |
| TC-AUTH-01 | 未登录用户 | 访问 `/bidding` | 可浏览大厅公开信息 |
| TC-AUTH-02 | 未认证企业 | 访问买家/卖家模块 | 当前前端可查看框架；后续真实业务接入时需要企业身份校验 |

## 回归关注点

- 顶部导航“竞价交易”仍指向 `/bidding`。
- 现货商城、供求信息、AI采购、集采大厅和平台介绍入口不受影响。
