# Test Cases

## 测试范围

- Feature ID: SL-FE-CROSS-APP-MANUAL-AUTH
- 测试负责人: Codex

## Happy Path

| 编号 | 场景 | 前置条件 | 步骤 | 期望结果 |
| --- | --- | --- | --- | --- |
| TC-01 | 卖家跳买家首页不自动登录 | 浏览器无买家登录态 | 登录 `/seller/login`，进入卖家后台，点击“买家首页” | 跳转到买家首页，买家头部展示“登录 / 注册” |
| TC-02 | 卖家 API 使用独立 token | 已登录卖家端 | 打开卖家商品、订单或设置页面 | 请求头携带卖家 `seller_token` 对应的 Bearer token |
| TC-03 | 买家登录态不被卖家登录覆盖 | 浏览器已有买家登录态 | 登录卖家端后返回买家首页 | 买家端仍读取原买家 `buyer_token` 登录态 |

## Exception Path

| 编号 | 场景 | 前置条件 | 步骤 | 期望结果 |
| --- | --- | --- | --- | --- |
| TC-EX-01 | 卖家 token 过期 | 已有过期 `seller_token` | 打开卖家受保护页面 | 清理卖家态并跳转卖家登录，不清理买家端登录态 |
| TC-EX-02 | 旧版共享 token 残留 | 浏览器存在旧版通用 `token/user` | 打开买家首页或卖家后台 | 不再因为通用 `token/user` 自动恢复另一端身份，需要按目标端手动登录 |

## 权限测试

| 编号 | 角色 | 场景 | 期望结果 |
| --- | --- | --- | --- |
| TC-AUTH-01 | seller | 从卖家中心进入买家首页 | 不后台切换为买家登录态 |
| TC-AUTH-02 | buyer | 买家端显式进入卖家中心 | 仍按现有买家端显式切换流程处理 |

## 回归关注点

- 买家端购物车、订单、工作台仍能读取买家 token。
- 卖家端商品、订单、仓库页面仍能读取卖家 token。
- 卖家退出不误清理买家端新命名的登录态。
