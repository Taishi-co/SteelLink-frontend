# Feature Spec

## 基本信息

- Feature ID: SL-FE-CROSS-APP-MANUAL-AUTH
- Feature 名称: 买家卖家入口取消跨应用自动登录
- 负责人: Codex
- 目标上线环境: Web 前端

## 背景

生产环境中，用户从卖家中心点击“买家首页”会因为买家端和卖家端共用 `token` 与互写用户缓存，被买家端识别为已登录状态。当前需求是保留入口跳转，但不要在跳转过程中自动完成买家登录或后台切换身份。

## 范围

### In Scope

- 卖家端登录态使用独立 `seller_token`。
- 卖家登录与用户刷新不再写入 `buyer_user`。
- 买家登录与用户刷新不再写入 `seller_user`。
- 保留卖家中心“买家首页”普通跳转入口。

### Out of Scope

- 不调整后端鉴权接口。
- 不新增角色切换接口。
- 不调整买家端和卖家端的显式登录页面。

## 交互与页面影响

- 受影响页面: 卖家中心顶部“买家首页”、买家首页顶部登录状态、买家端“卖家中心”入口。
- 新增页面: 无。
- 路由变化: 无。
- 菜单变化: 无。

## 数据与接口影响

- 受影响 API: 买家端与卖家端 axios 鉴权请求头取 token 的来源。
- 请求/响应变化: 无。
- 环境变量变化: 无。

## 权限影响

- 受影响角色: buyer / seller / enterprise 用户。
- 新增/调整权限: 无；仅调整前端登录态隔离。

## 验收标准

1. 只登录卖家端后点击“买家首页”，买家首页不展示为买家已登录状态。
2. 只登录买家端后进入“卖家中心”，卖家端需要独立登录，不从 `buyer_user` 自动恢复卖家身份。
3. 买家端 API 仍使用买家 `token`，卖家端 API 使用 `seller_token`。
