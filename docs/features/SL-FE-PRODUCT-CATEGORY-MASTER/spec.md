# SL-FE-PRODUCT-CATEGORY-MASTER Spec

## 背景

买家端商城导航从商品列表反推品类，商品列表筛选和卖家创建商品页使用硬编码品类数组，线上新增品类会出现导航、筛选、商家发布不一致。

## 目标

- 买家商城导航读取后端统一品类接口。
- 买家商品筛选读取同一品类接口，导航跳转的 `category` 参数必须可被筛选识别。
- 卖家商品创建页读取同一品类接口，同时允许输入新业务品类。
- 前台展示优先使用管理员配置的 `display_name` 和 `image_url`。

## 非目标

- 本次不调整商品详情和订单详情的历史品类字段。
- 本次不新增独立品类申请审批页。
