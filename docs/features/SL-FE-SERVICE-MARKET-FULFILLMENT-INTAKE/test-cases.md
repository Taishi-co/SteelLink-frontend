# SL-FE-SERVICE-MARKET-FULFILLMENT-INTAKE Test Cases

## 测试范围

- Feature ID: SL-FE-SERVICE-MARKET-FULFILLMENT-INTAKE
- 测试负责人: Codex

## Happy Path

| 编号 | 场景 | 前置条件 | 步骤 | 期望结果 |
| --- | --- | --- | --- | --- |
| TC-01 | 已有货物找物流 | 已登录且存在物流资源 | 点击委托运输并提交 | 调用真实物流委托接口，成功后提示物流商可接单 |
| TC-02 | 运输履约保障 | 填写保障类型和金额 | 提交物流委托 | 物流委托创建成功后创建履约保障 |
| TC-03 | 已有货物租仓 | 已登录且存在仓库资源 | 点击租仓存货并提交 | 调用仓储托管接口，创建待处理入库需求 |
| TC-04 | 闲置仓库上架 | 仓储方填写仓库信息 | 提交上架仓库 | 调用仓库资源创建接口并进入待审核 |
| TC-05 | 物流商上架线路 | 物流方填写线路信息 | 提交上架物流 | 调用物流资源创建接口并进入待审核 |
