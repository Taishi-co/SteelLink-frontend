# Test Cases

## 测试范围

- Feature ID: SL-FE-MATCHING-API-INTEGRATION
- 测试负责人: Codex

## Happy Path

| 编号 | 场景 | 前置条件 | 步骤 | 期望结果 |
| --- | --- | --- | --- | --- |
| TC-01 | 查看统计 | 后端服务可用 | 打开 `/matching` | 已发布信息数、撮合成功数、撮合金额数、今日新增数来自接口 |
| TC-02 | 查看四类信息 | 后端存在供求信息 | 打开 `/matching` | 供应、求购、仓储、物流板块展示接口数据 |
| TC-03 | 发布供应 | 已登录 | 点击发布供应并提交表单 | 调用 `POST /supply-demands`，成功后刷新页面数据 |
| TC-04 | 查看我的发布 | 已登录且有发布记录 | 打开 `/matching` | 我的发布展示当前用户记录 |
| TC-05 | 智能推荐 | 已登录且我的发布可匹配公开信息 | 打开 `/matching` | 推荐区展示基于真实数据派生的匹配结果 |

## Exception Path

| 编号 | 场景 | 前置条件 | 步骤 | 期望结果 |
| --- | --- | --- | --- | --- |
| TC-EX-01 | 无公开数据 | 后端列表为空 | 打开 `/matching` | 信息板块展示空状态 |
| TC-EX-02 | 未登录发布 | 未登录 | 点击发布按钮 | 提示先登录，不调用发布接口 |
| TC-EX-03 | 后端不可用 | API 请求失败 | 打开 `/matching` | 展示加载失败提示，不展示假数据 |

## 权限测试

| 编号 | 角色 | 场景 | 期望结果 |
| --- | --- | --- | --- |
| TC-AUTH-01 | 游客 | 查看统计和公开列表 | 可访问 |
| TC-AUTH-02 | 游客 | 查看我的发布 | 展示登录提示或空状态 |
| TC-AUTH-03 | 买家用户 | 发布供求信息 | 可提交 |

## 回归关注点

- 现货商城、AI采购、竞价交易导航不受影响。
- API 401 仍应走现有登录跳转逻辑。
- `VITE_API_URL` 配置不变。
