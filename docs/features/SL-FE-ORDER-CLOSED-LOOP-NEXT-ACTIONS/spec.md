# 订单闭环操作完成后的下一步引导

## 背景

订单闭环中的买方、卖方、仓储方、物流方、资金方操作完成后，原成功弹窗普遍只提供“回工作台/订单页”。这会打断用户在详情页核对状态、连续处理同一订单的操作节奏。

## 交互规则

1. 成功弹窗必须可关闭，支持右上角关闭和点击遮罩关闭。
2. 成功弹窗必须提供“留在当前页”类次按钮，用户不应被强制跳转。
3. 主按钮代表推荐下一步：买方可回订单列表或留在详情跟进；卖方可打开订单详情；服务方可切换到推荐工作区。
4. 弹窗文案需要明确说明下一责任方，不只展示“已完成”。
5. `message.success` 适用于轻量动作；会影响订单闭环状态的动作继续使用成功弹窗。

## 角色流程梳理

| 角色 | 当前操作 | 推荐下一步 | 弹窗主按钮 |
| --- | --- | --- | --- |
| 买方 | 买方确认订单 | 留在订单详情签署合同 | 留在详情签合同 |
| 买方 | 签署交易合同 | 等待对方签署或继续看详情 | 留在详情跟进 |
| 买方 | 上传支付凭证 | 等待卖方确认收款/发起物流 | 查看订单列表 |
| 买方 | 申请融资 | 等待资金方风控审批 | 查看订单列表 |
| 买方 | 确认融资方案 | 等待资金方生成债务合同 | 留在详情跟进 |
| 买方 | 签署融资合同并缴费 | 等待资金方放款 | 留在详情跟进 |
| 买方 | 验货/确认收货 | 等待卖方对账 | 查看订单列表 |
| 卖方 | 确认订单/确认条款 | 等待买方确认或签署合同 | 查看订单详情 |
| 卖方 | 确认收款 | 发起物流竞价或等待提货 | 查看订单详情 |
| 卖方 | 发起物流竞价 | 等待物流方报价 | 查看订单详情 |
| 卖方 | 对账/归档 | 订单闭环归档 | 查看订单详情 |
| 仓储方 | 确认仓库条件 | 等待买卖双方推进订单 | 查看推荐工作区 |
| 仓储方 | 更新出入库/物流协同节点 | 继续处理仓储作业或等待物流/买方 | 查看推荐工作区 |
| 物流方 | 报价/推进物流节点 | 等待买方/仓储/资金方对应节点 | 查看推荐工作区 |
| 资金方 | 风控审批 | 等待买方确认授信 | 查看推荐工作区 |
| 资金方 | 生成债务合同 | 等待买方签署并缴费 | 查看推荐工作区 |
| 资金方 | 放款/质押/释放 | 继续监管货权或归档链路 | 查看推荐工作区 |

## 本次实现范围

1. 改造买方订单详情页成功弹窗，支持关闭/留在当前页/推荐动作。
2. 改造卖方订单工作台成功弹窗，主按钮打开订单详情，次按钮留在列表。
3. 改造仓储、物流、资金方服务工作台成功弹窗，主按钮切换推荐工作区，次按钮留在当前页。
4. 不改后端订单状态机，不改变已有业务接口。
