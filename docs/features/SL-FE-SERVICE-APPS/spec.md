# Feature Spec

## 基本信息

- Feature ID: SL-FE-SERVICE-APPS
- Feature 名称: 物流、仓储、资金服务前端应用原型
- 负责人: Codex
- 目标上线环境: 前端预览环境

## 背景

SteelLink 当前前端只有买家端和卖家端。平台业务还需要物流平台、仓储平台和资金服务平台，其中买家侧应能像欧冶物流服务入口一样把仓储与运输作为履约服务一起浏览和发起需求；物流方、仓储方、资金服务方则需要独立工作后台承接订单、容量、风控和回款等业务流。

参考外部公开信息，欧冶物流平台面向大宗物资流通，覆盖仓储服务、运输服务、加工服务、物流交易、控货监管等范围。本 feature 只参考业务分类和买家入口形态，不复制页面资产或交互实现。

## 范围

### In Scope

- 买家端新增物流仓储服务市场页面，合并展示仓储、运输、监管和增值服务。
- 新增物流方后台前端应用，用于运单承接、车辆线路、在途异常和结算概览。
- 新增仓储方后台前端应用，用于仓容、入出库预约、库存监管和作业看板。
- 新增资金服务方后台前端应用，用于融资申请、授信、放款和贷后监控。
- 根 package scripts 增加新应用 dev/build 入口。

### Out of Scope

- 后端 API、数据库、鉴权、真实订单状态流转。
- 物流、仓储、资金服务的生产部署脚本。
- 角色登录体系合并与权限矩阵落库。

## 交互与页面影响

- 受影响页面: `apps/buyer-app/src/components/Layout/HomeHeader.tsx`
- 新增页面: `apps/buyer-app/src/pages/ServiceMarket/index.tsx`
- 新增应用:
  - `apps/logistics-app`
  - `apps/warehouse-app`
  - `apps/finance-app`
- 路由变化:
  - 买家端新增 `/service-market`
  - 物流后台使用 `/logistics`
  - 仓储后台使用 `/warehouse`
  - 资金服务后台使用 `/finance`
- 菜单变化: 买家端主导航新增“物流仓储”

## 数据与接口影响

- 受影响 API: 无
- 请求/响应变化: 无
- 环境变量变化: 无
- 当前数据来源: 前端静态模拟数据，用于业务逻辑讨论和页面评审。

## 权限影响

- 受影响角色: 买家、物流商、仓储商、资金方
- 新增/调整权限: 本阶段不改鉴权实现；后续需要在 `docs/domain/role-permission-matrix.md` 增补独立应用入口与后台权限。

## 验收标准

1. 买家可从首页导航进入物流仓储服务市场，并同时看到仓储与运输服务能力。
2. 物流方、仓储方、资金服务方分别有独立可构建的前端应用。
3. 每个后台都有概览指标、待办事项、核心业务表格和下一步业务判断入口。
4. 不依赖后端即可完成前端业务讨论和页面走查。
