# Test Cases

| ID | 场景 | 前置条件 | 操作 | 预期 |
| --- | --- | --- | --- | --- |
| TC-01 | 全部订单查看详情 | 仓储方已登录且存在参与订单 | 进入 `/warehouse/`，打开“全部订单”，点击“查看” | 打开订单详情弹窗，展示基础信息、仓储交付、商品明细和履约事件 |
