# SL-FE-WAREHOUSE-ORDER-DETAIL

## 背景

生产 `/warehouse/` 仓储方工作台的“全部订单”表格中，“查看”只是静态标签，无法打开订单详情。仓储方需要在工作台内查看自己参与的订单、商品明细、仓库交付信息和履约事件。

## 范围

- 修改 `apps/warehouse-app` 的订单表格操作列。
- 接入已有 `GET /orders/:id` 与 `GET /orders/:id/events` 前端 service。
- 增加仓储方订单详情弹窗，展示订单基础信息、仓储交付信息、商品明细和履约事件。

## 非范围

- 不调整订单状态机。
- 不新增仓储方订单编辑动作。
- 不改变买家端、卖家端、物流端页面。

## 验收标准

1. “全部订单”和“待确认订单”表格里的“查看”可点击。
2. 点击“查看”后加载订单详情与事件记录。
3. 订单详情加载失败时给出错误提示，不影响列表刷新与确认/打回动作。
